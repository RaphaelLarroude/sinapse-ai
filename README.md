# Sinapse AI

**Sinapse AI** é um hub de inteligências artificiais que reúne as principais ferramentas de IA em um só lugar.

O projeto inclui:

- **Synapse Code**: ambiente voltado para programação, criação de sites, apps, automações e compatibilidade com a proposta do Codex da OpenAI.
- **Synapse Work**: hub de chat, estudo, produtividade, escrita e organização.
- **Versão web** já planejada, com aplicativos para **Android** e **iPhone** previstos para o futuro.
- **Calculadora de economia** para comparar o custo de assinar várias IAs separadamente com o plano Sinapse de **R$ 30/mês**.
- **Metas comunitárias** para medir interesse, destravar preview, geração de imagens e desenvolvimento dos aplicativos.

## Como publicar no GitHub Pages

1. Acesse o repositório `sinapse-ai`.
2. Vá em **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/ (root)`.
5. Clique em **Save**.
6. Em alguns minutos, o site ficará disponível em:

`https://raphaellarroude.github.io/sinapse-ai/`
